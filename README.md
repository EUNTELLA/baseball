# 다음 투구의 제구 성공 확률 예측

2019~2024 시즌의 투구 데이터를 학습하여 2025 시즌 각 투구의 **제구 성공 확률**을 예측하는 프로젝트입니다.

학습 데이터에는 투구별 입력 정보와 제구 성공 여부인 `target`이 포함됩니다. 2025 시즌 평가 데이터의 `target`은 비공개이며, 모델은 각 투구가 제구에 성공할 확률을 제출해야 합니다.

## 문제 정의

| 구분 | 시즌 | 입력 정보 | Target | 활용 목적 |
| --- | --- | --- | --- | --- |
| 학습 데이터 | 2019~2024 | 투구별 경기 상황, 경기 중요도, 과거 이력, Trackman 과거 로그 | 공개 | 패턴 학습 및 모델 검증 |
| 평가 데이터 | 2025 | 투구별 입력 정보 | 비공개 | 제구 성공 확률 예측 |

이 과제는 각 투구를 다음 두 범주로 구분하는 **이진 분류 문제**입니다.

- `target = 1`: 제구 성공
- `target = 0`: 제구 실패

모델의 최종 출력은 `0` 또는 `1`이 아니라 `0~1` 범위의 성공 확률입니다.

```text
control_success_probability = P(target = 1 | 투구별 입력 정보)
```

## 전체 분석 흐름

```text
2019~2024 시즌 학습 데이터
경기 상황 + 경기 중요도 + 과거 이력 + Trackman 로그 + target
                              ↓
                    데이터 검증 및 전처리
                              ↓
                   시점 기준 파생변수 생성
                              ↓
                    시간 순서 기반 모델 검증
                              ↓
                  2019~2024 전체 데이터 학습
                              ↓
                       2025 시즌 예측
                              ↓
                    투구별 성공 확률 제출
```

## 데이터 구조

실제 컬럼명과 단위는 공식 데이터 명세를 기준으로 확정합니다. 아래 표는 제공된 데이터를 분석 목적에 따라 분류한 구조입니다.

### 1. 경기 상황 정보

투구가 발생한 순간의 볼카운트, 아웃카운트, 이닝 및 주자 상황을 나타냅니다.

| 정보 | 설명 | 활용 예시 |
| --- | --- | --- |
| 볼카운트 | 투구 전 볼 개수 | 볼이 많을 때 스트라이크를 던지려는 경향 분석 |
| 스트라이크카운트 | 투구 전 스트라이크 개수 | 유리하거나 불리한 카운트별 제구 차이 분석 |
| 아웃카운트 | 투구 시점의 아웃 개수 | 아웃 상황에 따른 투구 전략 변화 분석 |
| 이닝 | 현재 경기 이닝 | 경기 초반·중반·후반의 제구 변화 분석 |
| 점수차 | 투수 팀과 상대 팀의 점수 차이 | 리드·동점·열세 상황의 압박 차이 반영 |
| 주자 상황 | 각 루의 주자 존재 여부 | 득점권 및 주자 견제 상황 반영 |

주자 상황은 `주자 없음`, `1루`, `2루`, `3루`, `1·2루`, `1·3루`, `2·3루`, `만루`와 같이 범주화하거나 각 루의 점유 여부를 별도 변수로 표현할 수 있습니다.

### 2. 경기 중요도 정보

현재 투구가 경기 결과에 미치는 영향과 압박 수준을 나타냅니다.

| 정보 | 설명 | 활용 예시 |
| --- | --- | --- |
| 기대승률 | 현재 경기 상황에서 투수 팀이 승리할 확률 | 승리 가능성이 높은 상황과 낮은 상황 비교 |
| 상황중요도 | 현재 플레이가 기대승률에 미칠 수 있는 영향 | 고압박 상황에서 제구 성공 확률 변화 분석 |

기대승률과 상황중요도는 경기 상황을 이용해 계산된 값일 수 있으므로, 해당 투구 이후의 결과가 계산에 포함되지 않았는지 확인해야 합니다.

### 3. 과거 이력 정보

현재 투구 시점까지 누적되거나 최근 경기에서 관측된 선수의 과거 성과를 나타냅니다.

| 정보 | 설명 | 활용 예시 |
| --- | --- | --- |
| `asof_*` 누적 통계 | 현재 투구 직전까지 계산된 누적 성과 | 투수의 장기적인 제구 수준 표현 |
| 최근 경기 성과 | 최근 경기 또는 최근 일정 기간의 성과 | 단기 컨디션과 제구 변화 반영 |
| 과거 구종 사용 패턴 | 이전 투구에서 사용한 구종과 구종별 비율 | 다음 투구 선택 및 구종별 제구 차이 반영 |

`asof_*` 변수는 반드시 **현재 투구 이전 데이터만** 사용해야 합니다. 현재 투구의 결과나 미래 경기 정보가 포함되면 데이터 누수가 발생합니다.

구체적인 파생변수 후보는 다음과 같습니다.

| 파생변수 후보 | 설명 |
| --- | --- |
| 시즌 누적 제구 성공률 | 현재 투구 직전까지의 누적 성공률 |
| 최근 N개 투구 성공률 | 최근 5·10·20개 투구의 성공률 |
| 최근 경기 성공률 | 직전 경기 또는 최근 3경기의 성공률 |
| 구종별 누적 성공률 | 구종별 과거 제구 성공률 |
| 구종 사용 비율 | 최근 N개 투구에서 특정 구종을 사용한 비율 |
| 연속 성공·실패 횟수 | 현재 투구 직전까지 이어진 성공 또는 실패 길이 |
| 휴식일 | 직전 등판 이후 경과 일수 |

### 4. Trackman 과거 로그

2019~2024 시즌에 측정된 투구 물리 특성과 릴리스 정보를 나타냅니다.

| 정보 범주 | 포함 정보 | 활용 예시 |
| --- | --- | --- |
| 구속 | 투구 속도 | 평소보다 구속이 낮거나 높은 상황 탐지 |
| 회전수 | 분당 회전수 등 회전 관련 측정값 | 구종 품질과 투구 상태 반영 |
| 무브먼트 | 수평·수직 방향의 공 움직임 | 구종 특성과 제구 난이도 반영 |
| 릴리스 정보 | 릴리스 높이, 좌우 위치, 익스텐션 등 | 투구 동작의 일관성과 변화 탐지 |

Trackman 값은 절대값뿐 아니라 투수 개인의 평소 수준과 비교한 상대값도 유용할 수 있습니다.

| 파생변수 후보 | 계산 예시 |
| --- | --- |
| 구속 편차 | 현재 구속 − 투수·구종별 과거 평균 구속 |
| 회전수 편차 | 현재 회전수 − 투수·구종별 과거 평균 회전수 |
| 릴리스 편차 | 현재 릴리스 위치와 과거 평균 위치 사이의 거리 |
| 무브먼트 편차 | 현재 무브먼트와 투수·구종별 평균의 차이 |
| 최근 안정성 | 최근 N개 투구의 구속·릴리스·무브먼트 표준편차 |

2025년 예측 시 사용할 수 있는 Trackman 정보의 시점과 범위는 공식 데이터 명세를 확인해야 합니다. 예측 대상 투구의 결과 이후에 측정되는 정보라면 입력 변수로 사용할 수 없습니다.

## 데이터 분할 및 검증

야구 투구 데이터는 시간 순서가 있으므로 전체 데이터를 무작위로 섞는 검증은 사용하지 않습니다. 미래 시즌의 정보가 과거 시즌 예측에 포함되지 않도록 시즌 기준 검증을 적용합니다.

| 단계 | 학습 구간 | 검증 구간 | 목적 |
| --- | --- | --- | --- |
| 검증 1 | 2019~2022 | 2023 | 과거 데이터로 다음 시즌 예측 |
| 검증 2 | 2019~2023 | 2024 | 최신 시즌에 대한 일반화 성능 확인 |
| 최종 학습 | 2019~2024 | 없음 | 2025 평가 데이터 예측 |

필요하면 시즌 내부에서도 날짜 순서를 유지하는 시계열 교차 검증을 추가합니다.

## 데이터 누수 방지

다음 정보는 모델 성능을 비정상적으로 높일 수 있으므로 생성 시점을 확인해야 합니다.

- 현재 투구의 `target`이 포함된 누적 통계
- 경기 종료 후 계산된 최종 기록
- 2025 시즌 이후의 선수 통계
- 현재 투구 이후의 구종이나 경기 결과
- 평가 데이터의 전체 분포를 이용해 미리 계산한 미래 통계

모든 누적·최근 기록 변수는 현재 투구 직전 시점으로 한 칸 이동한 값, 즉 `shift(1)`과 같은 방식으로 생성해야 합니다.

## 모델링 계획

### 1. 기준 모델

- 전체 학습 데이터의 평균 성공률
- 투수별 과거 평균 성공률
- Logistic Regression

### 2. 트리 기반 모델

- Random Forest
- HistGradientBoosting
- XGBoost, LightGBM 또는 CatBoost

범주형 변수가 많고 변수 사이의 비선형 관계가 예상되므로 트리 기반 부스팅 모델을 주요 후보로 사용합니다.

### 3. 확률 보정

대회의 제출값이 성공 확률이므로 분류 정확도뿐 아니라 확률 자체의 신뢰도가 중요합니다.

- Platt Scaling
- Isotonic Regression
- 검증 데이터 기반 확률 보정

## 평가 지표

공식 평가 지표가 제공되면 해당 지표를 최우선으로 사용합니다. 성공 확률 예측에서 확인할 수 있는 일반적인 보조 지표는 다음과 같습니다.

| 지표 | 의미 |
| --- | --- |
| Log Loss | 정답에 낮은 확률을 부여한 예측에 큰 페널티 부여 |
| Brier Score | 예측 확률과 실제 결과 사이의 평균 제곱 오차 |
| ROC-AUC | 성공 투구와 실패 투구를 구분하는 순위 성능 |
| Calibration Error | 예측 확률과 실제 성공 비율의 일치 정도 |

## 제출 데이터

제출 파일은 공식 샘플 제출 파일의 ID, 행 순서, 컬럼명을 그대로 유지해야 합니다.

개념적인 제출 구조는 다음과 같습니다.

| 투구 식별자 | 제구 성공 확률 |
| --- | ---: |
| `P20250001` | `0.8732` |
| `P20250002` | `0.2147` |

확률값은 반드시 `0~1` 범위에 있어야 하며, 누락값이 없어야 합니다.

## 개발 로드맵

### 1단계: 데이터 이해

- 공식 컬럼과 데이터 타입 확인
- `target` 정의 및 분포 확인
- 결측치와 이상값 분석
- 선수·시즌·경기·투구 식별자 확인

### 2단계: 검증 환경

- 2023·2024 시즌 기반 시간 순서 검증 구성
- 공식 평가지표 구현
- 평균 확률 기준 모델 생성

### 3단계: 특징 생성

- 경기 상황 변수 전처리
- `asof_*` 누적 통계 검증
- 최근 N개 투구 및 경기 성과 생성
- 구종 사용 패턴 생성
- Trackman 개인 기준 편차 생성

### 4단계: 모델 학습

- Logistic Regression 기준 모델
- 트리 기반 부스팅 모델 비교
- 변수 중요도와 오류 사례 분석
- 예측 확률 보정

### 5단계: 최종 예측

- 2019~2024 전체 데이터로 최종 학습
- 2025 시즌 성공 확률 예측
- 제출 파일 형식 및 확률 범위 검증
- 학습·예측 과정 재현 자동화
