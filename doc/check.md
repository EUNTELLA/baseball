# 위반 사유

LG Aimers 9기 온라인 해커톤(Phase 2) 제출 코드 모니터링 과정에서 평가 데이터(test.csv)의 다른 행 또는 전체 분포를 활용하는 사례가 다수 확인되고 있고 실격 사례도 지속적으로 발생하고 있습니다.



본 해커톤은 추론 코드와 모델을 직접 제출하는 코드 제출 방식으로 진행되고 있습니다.

운영진은 제출된 코드의 추론 과정을 검토할 수 있으며, 규칙 위반 여부를 확인할 수 있습니다.



1) 반드시 지켜야 할 핵심 원칙
'평가 데이터의 각 행은 독립적으로 예측되어야 합니다.'

즉, 특정 행 A의 예측값은 아래 정보만으로 생성되어야 합니다.

- 행 A에 포함된 입력 변수
- 행 A의 입력 변수만을 이용해 생성한 파생변수
- 주최 측이 제공한 공식 학습 데이터
- 공식 학습 데이터만을 이용해 생성한 통계·모델·파생변수


2) 허용되지 않는 방식
아래와 같은 방식은 정상적인 추론 절차로 인정되지 않습니다.

test.csv 내 다른 행을 이용한 누적 통계 생성
test.csv 내 다른 행을 이용한 rolling / lag feature 생성
test.csv 전체의 평균, 분포, 빈도, 순위 등을 이용한 예측값 보정
같은 선수, 팀, 월, 경기 단위로 평가 데이터 내 다른 행을 집계하는 방식
평가 데이터상 시점이 더 과거로 보이는 행을 이용해 현재 행의 피처를 생성하는 방식
평가 데이터에 시점 정보가 포함되어 있더라도,

같은 test.csv 안의 다른 행은 현재 예측 대상 행의 추론에 사용할 수 없습니다.



3) 쉽게 이해할 수 있는 예시
어떤 행의 예측값은 아래 두 경우 모두 동일해야 합니다.

test.csv에 해당 행 1개만 있는 경우
test.csv에 전체 평가 데이터가 함께 있는 경우
두 경우의 예측값이 달라진다면, 평가 데이터의 다른 행이 추론에 영향을 준 것으로 볼 수 있습니다.



4) 생성 AI 사용 관련 유의사항
생성 AI를 활용하여 코드를 작성하는 것은 대회 규칙상 금지되지 않습니다.

다만 생성 AI가 작성한 코드라 하더라도,

최종 제출 코드가 대회 규칙을 준수하는지 확인할 책임은 참가자 본인에게 있습니다.

규칙 검토 없이 생성된 코드를 그대로 제출하여 발생하는 불이익은 참가자에게 귀속됩니다.


5) 리더보드 제출 이후 요청 관련 안내
규칙을 충분히 숙지하지 않았거나, 제출 전 코드를 점검하지 않았다는 사유는 면책 사유로 인정되지 않습니다.

또한 제출 이후 문제를 인지하여 특정 제출물의 제외 또는 삭제를 요청하더라도, 이미 제출된 리더보드 제출은 규칙 검토 대상에 포함됩니다.

모든 리더보드 제출은 제출 시점부터 대회 규칙을 준수해야 하며, 규칙을 준수하지 않은 제출이 확인되는 경우 규정에 따라 실격에 해당할 수 있습니다.



참가자 여러분께서는 제출 전 반드시 추론 로직을 점검하시어,

규칙 위반으로 인한 불이익이 발생하지 않도록 각별히 유의해 주시기 바랍니다.

제출물에 대한 모니터링 및 내부 검증은 대회 기간 내내 지속적으로 진행됩니다.
