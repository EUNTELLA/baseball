# 야구 기본 지식

이 문서는 KBO 경기 데이터를 수집하고 분석할 때 필요한 야구의 기본 개념과 주요 기록을 정리한다.

## 1. 경기의 목적과 기본 진행

야구는 두 팀이 공격과 수비를 번갈아 하며 더 많은 득점(`R`, Run)을 올리는 경기다.

- 정규 경기는 보통 9이닝으로 진행한다.
- 한 이닝은 원정 팀이 공격하는 초와 홈 팀이 공격하는 말로 나뉜다.
- 수비 팀이 아웃 3개를 잡으면 공수 교대한다.
- 공격 팀 선수는 정해진 타순에 따라 한 명씩 타석에 들어선다.
- 타자가 1루, 2루, 3루를 거쳐 홈 플레이트에 도달하면 1점을 얻는다.
- 9회초 종료 시 홈 팀이 앞서고 있다면 9회말은 진행하지 않는다.
- 동점 경기의 연장 이닝과 무승부 처리 방식은 리그 및 시즌 규정에 따라 달라질 수 있다.

## 2. 스트라이크, 볼, 아웃

### 투구 판정

- **스트라이크**: 타자가 헛스윙하거나, 파울을 치거나, 스윙하지 않은 공이 스트라이크 존을 통과한 경우다.
- **볼**: 타자가 스윙하지 않았고 공이 스트라이크 존을 벗어난 경우다.
- 스트라이크 3개면 삼진 아웃이다.
- 볼 4개면 볼넷으로 1루에 출루한다.
- 일반적인 파울은 스트라이크로 계산하지만, 스트라이크가 2개인 상태의 파울은 번트 파울 등 일부 예외를 제외하면 삼진이 되지 않는다.
- 투수가 공을 던져 타자의 몸에 맞히면 일반적으로 몸에 맞는 공으로 출루한다.

### 대표적인 아웃

- **삼진**: 타자가 스트라이크 3개를 기록한다.
- **플라이 아웃**: 타구가 땅에 닿기 전에 수비수가 잡는다.
- **땅볼 아웃**: 타자가 1루에 도착하기 전에 수비가 공을 1루로 보낸다.
- **태그 아웃**: 베이스를 밟고 있지 않은 주자를 공을 가진 수비수가 태그한다.
- **포스 아웃**: 진루 의무가 있는 주자보다 먼저 수비수가 다음 베이스를 밟는다.
- 하나의 플레이에서 아웃 2개를 잡으면 병살, 3개를 잡으면 삼중살이다.

## 3. 경기장과 수비 포지션

수비에는 9명이 출전한다. 기록 데이터에서는 포지션 번호를 자주 사용한다.

| 번호 | 약어 | 포지션 | 주요 역할 |
|---:|---|---|---|
| 1 | P | 투수 | 타자에게 공을 던지고 투수 앞 타구를 처리한다. |
| 2 | C | 포수 | 투구를 받고 수비를 지휘하며 도루를 저지한다. |
| 3 | 1B | 1루수 | 1루 송구와 1루 주변 타구를 처리한다. |
| 4 | 2B | 2루수 | 1·2루 사이를 수비하고 병살 플레이에 참여한다. |
| 5 | 3B | 3루수 | 3루 주변의 빠른 타구와 번트를 처리한다. |
| 6 | SS | 유격수 | 2·3루 사이를 맡는 내야 수비의 중심이다. |
| 7 | LF | 좌익수 | 외야 왼쪽을 수비한다. |
| 8 | CF | 중견수 | 외야 중앙과 넓은 범위를 수비한다. |
| 9 | RF | 우익수 | 외야 오른쪽을 수비한다. |

지명타자(`DH`)는 투수 대신 타격하며 수비 포지션에는 포함되지 않는다.

## 4. 공격과 주루

### 타격 결과

- **단타(1B)**: 타자가 한 개의 베이스를 얻는 안타
- **2루타(2B)**: 타자가 두 개의 베이스를 얻는 안타
- **3루타(3B)**: 타자가 세 개의 베이스를 얻는 안타
- **홈런(HR)**: 타자와 주자 모두 홈까지 진루할 수 있는 타구
- **볼넷(BB)**: 볼 4개로 출루
- **몸에 맞는 공(HBP)**: 투구에 몸을 맞아 출루
- **희생번트(SH/SAC)**: 주자를 진루시키기 위해 타자가 자신의 아웃을 감수한 번트
- **희생플라이(SF)**: 외야 플라이 아웃과 함께 주자가 득점한 플레이
- **실책(E)**: 수비가 정상적으로 처리할 수 있는 플레이를 놓쳐 타자나 주자의 진루를 허용한 기록
- **야수 선택(FC)**: 수비가 타자 주자 대신 다른 주자를 잡으려 선택한 플레이

안타, 볼넷, 몸에 맞는 공처럼 타자가 아웃되지 않고 베이스에 나가는 것을 출루라고 한다. 실책이나 야수 선택에 의한 진루는 출루율 계산에서 출루로 인정되지 않는다.

### 주루

- 주자는 타구나 수비 상황에 따라 다음 베이스로 진루한다.
- 투구 중 주자가 다음 베이스를 빼앗으면 도루(`SB`)로 기록될 수 있다.
- 도루를 시도하다 아웃되면 도루 실패(`CS`)다.
- 플라이 타구가 잡히면 주자는 원래 베이스를 다시 밟은 뒤 진루해야 한다. 이를 태그업이라고 한다.

## 5. 타격 기록과 지표

### 기본 집계 기록

| 약어 | 이름 | 의미 |
|---|---|---|
| G | 경기 | 출전 경기 수 |
| PA | 타석 | 타자가 타격을 완료한 전체 기회 |
| AB | 타수 | 타석에서 볼넷, 몸에 맞는 공, 희생번트, 희생플라이 등을 제외한 횟수 |
| R | 득점 | 홈을 밟아 올린 점수 |
| H | 안타 | 실책 없이 안전하게 출루한 타구 수 |
| 2B / 3B | 2루타 / 3루타 | 각각 2개 또는 3개의 베이스를 얻은 안타 수 |
| HR | 홈런 | 홈런 수 |
| RBI | 타점 | 타자의 플레이로 들어온 득점 수. 일부 상황은 제외된다. |
| BB | 볼넷 | 볼넷으로 출루한 횟수 |
| HBP | 몸에 맞는 공 | 투구에 맞아 출루한 횟수 |
| SO 또는 K | 삼진 | 삼진을 당한 횟수 |
| SB / CS | 도루 / 도루 실패 | 도루 성공 및 실패 횟수 |

타석과 타수는 같은 개념이 아니다. 예를 들어 볼넷은 타석에는 포함되지만 타수에는 포함되지 않는다.

### 대표 비율 지표

#### 타율(AVG)

```text
AVG = H / AB
```

타수 중 안타를 친 비율이다. 볼넷 등 안타 이외의 출루 능력은 반영하지 못한다.

#### 출루율(OBP)

```text
OBP = (H + BB + HBP) / (AB + BB + HBP + SF)
```

타자가 아웃되지 않고 출루한 능력을 보여준다. 리그 또는 데이터 제공처의 세부 규정에 따라 분모·분자 처리에 예외가 있을 수 있다.

#### 장타율(SLG)

```text
TB  = 1B + (2 × 2B) + (3 × 3B) + (4 × HR)
SLG = TB / AB
```

`TB`는 총루타다. 장타율은 이름과 달리 비율이라기보다 타수당 평균 총루타를 나타낸다.

#### OPS

```text
OPS = OBP + SLG
```

출루 능력과 장타 능력을 간단히 함께 보는 지표다. 계산하기 쉽지만 서로 단위가 다른 두 지표를 더한다는 한계가 있다.

#### 삼진율과 볼넷율

```text
K%  = SO / PA
BB% = BB / PA
```

데이터 제공처에 따라 타석 대신 타자 상대 수 등 다른 분모를 사용할 수 있으므로 지표 정의를 함께 확인해야 한다.

## 6. 투수 기록과 지표

### 투수의 역할 구분

- **선발 투수**: 경기를 시작하는 투수
- **구원 투수**: 경기 도중 등판하는 투수
- **마무리 투수**: 주로 경기 후반의 리드를 지키기 위해 등판하는 투수

### 기본 집계 기록

| 약어 | 이름 | 의미 |
|---|---|---|
| G / GS | 경기 / 선발 경기 | 전체 등판 수와 선발 등판 수 |
| IP | 투구 이닝 | 투수가 잡은 아웃 수를 이닝으로 표현한 값 |
| H | 피안타 | 허용한 안타 수 |
| HR | 피홈런 | 허용한 홈런 수 |
| BB | 볼넷 | 허용한 볼넷 수 |
| HBP | 몸에 맞는 공 | 허용한 몸에 맞는 공 수 |
| SO 또는 K | 탈삼진 | 삼진으로 잡은 타자 수 |
| R | 실점 | 투수 등판 중 발생한 모든 실점 |
| ER | 자책점 | 실책 등의 영향을 제외하고 투수 책임으로 인정된 실점 |
| W / L | 승 / 패 | 공식 기록 규칙에 따라 부여된 승리 및 패전 |
| SV / HLD | 세이브 / 홀드 | 특정 리드 상황을 지킨 구원 투수 기록 |

투구 이닝의 소수 표기는 십진수가 아니다. `6.1이닝`은 6과 1/3이닝, `6.2이닝`은 6과 2/3이닝을 뜻한다. 계산할 때는 아웃 카운트로 변환하는 것이 안전하다.

### 대표 비율 지표

#### 평균자책점(ERA)

```text
ERA = (ER × 9) / IP
```

9이닝당 자책점을 나타낸다. 수비와 구장, 공식 기록원의 자책점 판정 영향을 받을 수 있다.

#### WHIP

```text
WHIP = (BB + H) / IP
```

이닝당 허용한 볼넷과 안타 수다. 몸에 맞는 공은 일반적인 WHIP 공식에 포함하지 않는다.

#### 9이닝당 기록

```text
K/9  = (SO × 9) / IP
BB/9 = (BB × 9) / IP
HR/9 = (HR × 9) / IP
```

서로 다른 투구 이닝을 기록한 투수를 비교할 때 사용한다.

#### 삼진/볼넷 비율(K/BB)

```text
K/BB = SO / BB
```

투수의 제구력과 타자를 압도하는 능력을 간단히 함께 보여준다. 볼넷이 0이면 0으로 나누는 문제가 생기므로 데이터 처리 규칙이 필요하다.

## 7. 승패와 투수 기록

팀의 승패와 투수 개인의 승패는 다르다. 팀이 이겨도 모든 투수에게 승리가 주어지는 것은 아니며, 공식 규칙에 따라 승리 투수 한 명과 필요한 경우 패전 투수 한 명이 정해진다.

- 선발승에는 일반적으로 최소 투구 이닝 등의 조건이 적용된다.
- 구원 투수의 승리는 등판 시점과 리드 변화에 따라 결정된다.
- 세이브와 홀드는 정해진 점수 차, 등판 시점, 경기 종료 여부 등의 조건을 충족해야 한다.
- 투수의 승수는 팀 공격력과 교체 시점의 영향을 크게 받으므로 투수의 개인 능력만을 나타내지는 않는다.

## 8. 선수와 경기 데이터의 관계

야구 데이터는 대체로 다음 단위로 나뉜다.

| 단위 | 예시 | 활용 |
|---|---|---|
| 시즌 | 시즌 타율, 시즌 순위 | 장기 성과 비교 |
| 경기 | 경기별 타석, 득점, 투구 이닝 | 일별 추세 분석 |
| 타석 | 타자, 투수, 결과, 주자 상황 | 타격 접근 및 상황 분석 |
| 투구 | 구종, 구속, 코스, 판정 | 투구 품질과 구종 분석 |
| 타구 | 타구 속도, 발사각, 방향 | 타구 품질 분석 |

시즌 합계만으로는 경기별 흐름을 복원할 수 없다. 이동평균이나 반등 신호를 분석하려면 최소한 선수·경기 단위 기록과 정확한 경기 날짜 및 식별자가 필요하다.

## 9. 데이터 분석 시 주의할 점

### 표본 크기

짧은 기간의 타율이나 ERA는 우연에 의해 크게 변할 수 있다. 최근 7경기와 시즌 전체처럼 서로 다른 구간을 함께 보고, 타석이나 투구 이닝 등 표본 크기도 반드시 표시해야 한다.

### 비율의 단순 평균

경기별 타율의 평균은 전체 타율과 다를 수 있다. 전체 기간의 타율은 경기별 비율을 평균 내지 말고 해당 기간의 안타 합계를 타수 합계로 나누어 계산한다. 출루율과 장타율도 구성 기록을 먼저 합산한 뒤 다시 계산한다.

### 맥락 차이

선수 기록은 상대 투수·타자, 구장, 날씨, 홈·원정, 수비, 타순, 부상, 리그 환경의 영향을 받는다. 서로 다른 시즌을 비교할 때는 경기 수와 규정 변화도 확인해야 한다.

### 식별자와 소속 팀

동명이인이 존재하고 선수는 시즌 도중 팀을 옮길 수 있다. 이름을 기본 키로 사용하지 말고 안정적인 선수 ID를 사용하며, 소속 팀은 경기 날짜를 기준으로 관리한다.

### 결측치와 0

기록이 없다는 것과 기록값이 0이라는 것은 다르다. 예를 들어 출전하지 않은 선수의 타수는 결측일 수 있고, 출전해 타수 없이 볼넷만 얻은 선수의 타수는 0일 수 있다.

### 공식 기록 정정

안타와 실책, 자책점 등은 경기 후 정정될 수 있다. 수집 시각과 원천 값을 보관하고 최근 경기 데이터를 일정 기간 다시 수집할 수 있도록 설계한다.

## 10. 자주 혼동하는 개념

| 개념 | 구분 |
|---|---|
| 타석과 타수 | 타석이 더 넓은 개념이며 볼넷 등은 타수에서 제외된다. |
| 득점과 타점 | 득점은 홈을 밟은 주자, 타점은 득점을 만들어 낸 타자에게 기록된다. |
| 실점과 자책점 | 실점은 모든 점수, 자책점은 투수 책임으로 인정된 점수다. |
| 안타와 출루 | 안타는 출루 방법 중 하나이며 볼넷, 몸에 맞는 공도 출루다. |
| 평균과 누적 | AVG, OBP, ERA는 비율이고 H, HR, SO는 누적 기록이다. |
| 6.1이닝과 6.1 | 6.1이닝은 6.1이라는 십진수가 아니라 6과 1/3이닝이다. |

## 11. 분석을 위한 최소 체크리스트
