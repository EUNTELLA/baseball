# 후속 실험 선별 기준

이 문서는 이미 충분한 근거가 쌓인 방향을 반복하지 않기 위한 작업 기준입니다. 여기서 제외한다는 것은 영구적으로 불가능하다는 뜻이 아니라, 현재 최고 모델을 넘어설 새로운 근거가 나오기 전까지 계산과 제출 예산을 배정하지 않는다는 뜻입니다.

현재 비교 기준은 `catboost-train-error-adjustment-031`, Public Score `1029.0832235020`입니다.

## 재검토 보류

### 모델 계열 교체

- RandomForest, HistGradientBoosting, LightGBM을 독립 주력 모델로 다시 학습
- Transformer 계열의 표 형식 인코더
- 조건별 파라미터 변형 모델과 잠재 상태 추적 모델

기존 CatBoost보다 일관된 개선을 만들지 못했거나 학습 비용 대비 추가 정보가 확인되지 않았습니다.

### 학습 안정화 기법

- 분포 구분용 보조 학습과 강건 최적화 목적함수
- 그룹별 최악 성능을 직접 줄이는 학습
- 시드 수, 반복 횟수, 트리 용량의 단순 확대

현재 병목은 예측 분산보다 시즌 변화와 조건별 오차에 있으므로 우선순위에서 제외합니다.

### 데이터 분할형 전문가

- 선발·불펜별 독립 모델
- 경기 유형별 독립 모델
- 특정 경기 유형만을 위한 별도 성공 분류기
- 불펜과 카운트를 동시에 나눈 세부 모델

행을 나누어 재학습하면 표본이 줄고 시즌별 구성 변화에 민감해졌습니다. 공통 모델을 유지한 조건부 후처리와 구분합니다.

공통 모델을 유지하면서 F 행에만 Train 기반 보정값을 추가하는 방식도 2023·2024 동시 개선 후보가 없어 종료했습니다. 새로운 행 단위 근거가 나오기 전에는 F 관련 모델과 후처리를 다시 열지 않습니다.

### 광범위한 사후 변환

- 예측 전체의 기울기와 절편을 함께 다시 적합
- 분산을 일괄적으로 줄이는 변환
- 여러 보정 채널을 한 번에 최적화하는 고차원 혼합
- 오래된 시즌까지 보정표 원천을 무조건 확대

시즌을 건너면 최적값이 달라지기 쉬우므로 단일 변경과 시간 순서 검증이 없는 경우 진행하지 않습니다.

투수의 공식 누적 투구 수가 적을수록 현재 세 보정을 약하게 적용하는 방식도 `k=50~1000` 전 구간에서 두 시즌 동시 개선 후보가 없었습니다. 현재 보정표 자체에 표본량 완화가 이미 들어 있으므로 행 단계에서 다시 줄이는 실험은 종료합니다.

### 부가 정보 확장

- 팀 단위 성공률 보정
- 시즌 상태를 별도 추정하는 집계 피처
- 선수·상황별 복잡한 부분 결합
- Trackman 구종 혼합을 독립 예측 채널로 추가

기존 피처와 중복되거나 다음 시즌에서 효과가 유지되지 않았으므로 보류합니다.

## 계속 허용하는 방향

### 행 단위 과거 오차 보정

현재 최고 점수를 만든 핵심 방향입니다. 같은 손 조합, 2스트라이크, 주자 존재처럼 현재 행만으로 판단할 수 있는 조건을 사용합니다. 보정값은 공식 Train에서 해당 시즌을 학습하지 않고 얻은 예측 오차로만 만듭니다.

### 실패 형태 기반 보조 성분

기존 MR/wayoff 보정처럼 공식 Train에서 유도한 보조 정답을 행별 예측에 사용하는 방향은 유지합니다. 새로운 성분은 기존 offset 위의 추가 이득이 확인될 때만 채택합니다.

F 행에만 기존 MR 또는 큰 이탈 보조 logit의 추가 계수를 주는 실험은 양·음 방향 여섯 계수 모두 2023·2024 동시 개선에 실패했습니다. 현재 보조 offset을 F 행에서 단순 증감하는 방식은 종료하며, 새로운 행 조건이나 독립적인 보조 정답이 있을 때만 다시 검토합니다.

가장 근접했던 큰 이탈 `+0.025`를 탐색 제출했으나 Public `1028.8717`로 현재 최고보다 `0.2115` 낮았습니다. 따라서 F 행에서 기존 실패유형 보조 확률의 계수만 조정하는 후보는 리더보드 근거까지 포함해 재검토 보류합니다.

2026-08-20에는 F 행의 순방향 성공모델 잔차를 별도 CatBoost 회귀기로 학습하고 `0.05~0.30` 강도를 비교했으나 동시 개선 후보가 없었습니다. F 전용 직접 모델, 상수 보정, 기존 보조 계수 조정과 단순 잔차 회귀까지 모두 실패했으므로 새로운 독립 신호 없이 F 전용 모델 구조를 반복하지 않습니다.

MR·큰 이탈 보조 채널을 3시드에서 6시드로 확대한 결과는 2023에서 약 `+5.3`이었지만 2024에서 약 `-1.75`였습니다. 6시드 Train 예측으로 전역 shift를 다시 계산해도 변화가 거의 없었으므로 보조 모델 시드 확대와 그에 따른 calibration 재계산은 재검토 보류합니다.

사용자 요청으로 6시드 보조 채널과 재계산 shift를 제출한 결과 Public `1009.4333`으로 현재 최고보다 `19.6499` 하락했습니다. 특히 production shift가 `-0.0690`까지 커지며 예측 수준을 과도하게 내렸으므로, 보조 시드 확대와 전역 수준 재적합을 결합하는 방식은 리더보드 근거까지 포함해 종료합니다.

공개 저장소에서 확인한 동적 기준확률 잔차 원리를 공식 `asof_*`만으로 독립 구현했으나 2022·2023·2024가 모두 하락하고 pooled BSS도 `-504.98` 악화됐습니다. 외부 최종 구조의 성과를 단일 기준확률·잔차 회귀기로 축약할 수 없으므로 이 모델 축은 확장하지 않고, 세 연도·pooled·오차상관 검증 방식만 이후 실험에 유지합니다.

## 실행 규칙

1. 현재 최고 모델에서 한 요소만 변경합니다.
2. 평가는 공식 Brier Skill Score만 사용합니다.
3. 과거 시즌으로 보정값을 만들고 이후 시즌에서 확인합니다.
4. test의 다른 행이나 전체 분포는 사용하지 않습니다.
5. 두 확인 시즌에서 같은 방향일 때만 전체 과정으로 진행합니다.
6. 기존 최고 ZIP은 새 결과가 확인될 때까지 보존합니다.
7. 보류 목록의 실험은 새로운 독립 근거가 문서화된 경우에만 다시 엽니다.

- 이전 시즌의 투수·타자 손 조합 자료를 추가하는 방식은 최신 확인에서 소폭 개선됐지만 그 이전 이동 구간이 음수여서 승격하지 않습니다.

따라서 새로운 독립 근거가 없는 한 모델 분할, 팀 통계, 역할 전문가, F 직접 모델, 오래된 자료 확대를 다시 실행하지 않습니다. 현재 최고 모델 위에서 새로운 행 단위 조건이 두 시즌 이상 안정적으로 추가 이득을 보일 때만 다음 실험으로 진행합니다.
