## 01. 최근 시즌 가중 RandomForest

```powershell
python 0814/01_weighted_recent_rf_submission.py
```

- 학습 시즌: 2023~2024
- 2023 가중치: `1.0`
- 2024 가중치: `1.5`
- 확률 오프셋: `-0.009683759059887942`
- 생성 파일: `0814/results/submit_rf_recent_weighted_15.zip`

추론은 각 평가 행의 입력값만 사용합니다. `test.csv` 내부 집계, 평균, 빈도, 순위, rolling 및 lag 피처는 사용하지 않으며, 샘플 검증에서 일괄 예측과 한 행씩 예측의 최대 차이가 `1e-12` 이하인지 확인합니다.
